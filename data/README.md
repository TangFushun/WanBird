# 内容与来源维护

`birds.json` 为图鉴数据，`sources.json` 为可引用资料目录。分类、坐标、照片和百科正文各自具有不同来源，不能互相替代。

- `content_review.status`：`draft` 表示种级正文待复核；`sourced` 表示按具体资料整理并附有段落出处，不表示鸟类专家审校。
- `summary_sources`、`anhui_sources`、各 `sections[].sources` 均引用 `sources.json` 的键；`source_ids` 按本页显示顺序列出这些键。
- 每项来源保存标题、发布机构、原文链接、发布日、本站查阅日和引用用途。未记录的日期使用 `null`，不得用文件修改时间补填。
- `iucn_evidence` 记录评级依据与评估年份。国家一级/二级保护与 IUCN 全球受威胁等级分别维护。引用旧评估或机构转述时，明确版本限制。
- 数据库入口链接仅帮助查阅，不能用来证明缺少种级出处的习性描述。基础资料暂保留待复核状态，不批量贴上“权威审核”标签。
- `dramas.json` 的 `science_sources` 对应科学知识出处；`story_note` 与 `footage_note` 分别说明故事创作和实拍素材核实状态。修改页面文字不会修改已制作的视频内容。

观测点位于 `public/static/data/occur/<id>.json`。今后下载时会另存 `<id>.meta.json`，记录真实下载时间、检索年份与坐标数量；旧数据未记录下载时间时显示“未记录”。不把坐标点数当作原始记录总数、现存个体数或完整分布。
